Research

What I work on

GPU kernels for operators that fall outside a framework's fused-kernel catalog, and the problem of trusting a system that writes them automatically. A loop that generates code is only as good as the gate that judges it, so most of my attention goes to the gate: what it can see, what the generator can reach, and whether a result that passes once still holds when the shape or the hardware changes.

  • Agentic code generation with verification in the loop
  • Triton and GPU performance analysis — roofline, bandwidth, occupancy
  • Reproducibility and measurement validity in systems benchmarking

Publications

GraphSynth: Agentic Triton Kernel Synthesis for Non-Standard Attention, Verified Across GPU Generations

Joshi Penta, Priyesh Shukla

A3: Agentic Approaches to Architecture, co-located with MICRO 2026 Paper + Poster

An LLM-driven Triton synthesis workflow expressed as a CHIA dataflow graph: four stages, exactly one agentic edge, and a correctness gate that is never registered as a tool — so the model being judged cannot reach it. Re-running on a second GPU generation showed the reported speedup nearly tripling while the kernels stayed identical, because the eager baseline is bandwidth-bound and the synthesized kernels are not.
